# ウミガメのスープ

2人で遊ぶ、水平思考パズル(ウミガメのスープ)バトル。親が問題を選び、子が「はい/いいえ」で
答えられる質問を重ねて、または自由記入でいつでも回答して、謎を解き明かす。
アキネーターバトルと同じ仕組み(Firestoreでリアルタイム同期、4桁の部屋コード、ログイン不要)
をベースに作っている。

## アキネーターバトルとの違い

- お題は親が自由記入するのではなく、同梱された問題集(`src/puzzles.js`、77問)から選ぶ
- 問題はタグで絞り込める(難易度・雰囲気・題材・仕掛けなど)
- 質問数は無制限。子はいつでも質問、いつでも回答できる
- 親の回答は5択(はい/いいえ/どちらでもない/部分的にはい/部分的にいいえ)に加えて自由回答も選べる
- 答えはpuzzles.jsという共有データに両端末とも最初からアクセスできるため、秘匿はあくまで
  画面上で表示しないという運用上の約束(アキネーターバトルのように「親の端末にしかない」
  わけではない)。そのぶん途中終了などの確定処理はシンプルになっている
- 親は選択中も対局中も、いつでも「答えを確認する」で正解を見られる

## 問題の出典

- `sui-hei.net` の良問ランキング上位50問
- `turtlenoir.com` のブログ記事(20問、著作権配慮のため要約・言い換え)
- その他の有名な水平思考パズル(7問、出典が明確でないものは`source`欄に明記)

各問題の`source`フィールドに出典を記載している。`data_raw/`と`build_puzzles.js`は
問題データを生成した際の作業ファイルで、gitには含めていない(`src/puzzles.js`が本体)。

## セットアップ

Firebaseプロジェクト(`umigame-soup-kamedono`、アキネーターバトルとは別プロジェクト)は
作成済み。`src/firebase-config.js`に実際の値が入っている。

```bash
firebase deploy --only firestore --project umigame-soup-kamedono
```

でセキュリティルールを反映できる。あとは`index.html`をHTTP/HTTPS配信するだけで動く
(ビルドツール不要)。

## セキュリティについて

アキネーターバトルと同じく、4桁の部屋コードを合言葉にした設計。ログイン機能はない。
